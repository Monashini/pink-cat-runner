# Mona Run – Pink Cat Runner Game

Mona Run is a browser-based endless runner game developed using HTML, CSS, and JavaScript. The project is inspired by the Chrome Dino Runner but redesigned with a customized character, themed visuals, and progressive gameplay mechanics.

---

## Project Overview

The game features a pink cat character that runs continuously while avoiding incoming brick obstacles. The objective is to survive as long as possible while the game speed increases over time.

This project demonstrates front-end game development concepts including canvas rendering, animation, collision detection, and event handling.

---

## Features

- Custom Pink Cat Player Character  
- Themed Visual Design (Pink, Purple, Blue palette)  
- Multiple Obstacle Shapes and Sizes  
- Progressive Speed Levels  
  - Slow  
  - Medium  
  - Fast  
  - Extreme  
- Score Tracking System  
- Start Screen and Game Over Overlay  
- Responsive Canvas Gameplay  

---
